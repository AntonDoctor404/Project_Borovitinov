# Базовая ИИ для работы с текстом

**Интеллектуальная панель для автоматической обработки текстовых документов по инструкциям пользователя.** Проект представляет собой инструмент, который считывает текстовые файлы форматов `.txt` и `.docx`, передает их содержимое локальной языковой модели вместе с техническим заданием (промтом) и сохраняет извлеченный или отредактированный результат в новый файл.

## Идея проекта

Основная идея заключается в создании легковесного и независимого от сторонних API инструмента для локальной автоматизации рутинной работы с текстами. Пользователю не нужно вручную копировать огромные абзацы в веб-интерфейсы нейросетей — скрипт берет на себя всю логику чтения структуры, отправки безопасного контекста в модель и генерации нового документа.

## Задачи проекта

* **Реализация парсинга:** Написание модулей для автоматического чтения и распознавания кодировок файлов `.txt` и текстовых блоков документов `.docx`.
* **Промпт-инжиниринг:** Настройка строгого системного контекста (system prompt) для предотвращения «галлюцинаций» модели и обеспечения ответов исключительно по делу.
* **Автоматизация вывода:** Реализация функции автосохранения готового текста с автоматическим присвоением постфикса `_processed`.

## Используемые технологии

* **Python** — основная среда разработки.
* **Transformers (Hugging Face)** — библиотека для загрузки и инференса нейросети.
* **Модель Qwen/Qwen2.5-0.5B-Instruct** — легковесная языковая модель, оптимизированная под выполнение инструкций.
* **Python-docx** — библиотека для работы с документами Microsoft Word.
